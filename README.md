# Python Text-Based Game

This is a personal project I have created for my profile. This game is a simple text-based adventure game featuring player classes, combat, and npc interactions. The majority of the code is created from scratch, with some parts having assistance from VS Code Copilot, and the one ost track is also created by me.

The combat has a unique aspect: if the player gets attacked, they can type a sequence of letters to attempt to parry the attack, in essence a text-based QTE (Quick Time Event), which was partially inspired by Clair Obscur's combat.

This project will recieve updates in the future, including expanding the player classes, the world, and the soundtrack. I hope that you enjoy this little passion project of mine!

## Features
- Turn-based text-based combat
- NPC interactions
